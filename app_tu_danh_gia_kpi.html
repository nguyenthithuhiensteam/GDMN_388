Đồng bộ dữ liệu với GitHub

Lưu toàn bộ dữ liệu bản tự đánh giá này thành 1 file JSON trong một GitHub repository, để có thể mở lại từ máy/trình duyệt khác. Cần một GitHub Personal Access Token — xem hướng dẫn tạo token bên dưới. Token chỉ được lưu trong trình duyệt của bạn (localStorage) và chỉ dùng để gọi thẳng tới api.github.com — không gửi cho bất kỳ máy chủ nào khác.
Hướng dẫn tạo Personal Access Token (PAT) trên GitHub
  1. Đăng nhập GitHub → bấm ảnh đại diện góc trên phải → Settings.
  2. Cuộn xuống cuối menu bên trái → Developer settings.
  3. Chọn Personal access tokens → Fine-grained tokens → Generate new token.
  4. Đặt tên token, chọn Resource owner là tài khoản/tổ chức chứa repository bạn sẽ lưu dữ liệu.
  5. Ở mục Repository access, chọn Only select repositories rồi chọn đúng repository đó (không cấp quyền cho repo khác).
  6. Ở mục Permissions → Repository permissions, tìm dòng Contents và đổi thành Read and write.
  7. Bấm Generate token, sao chép chuỗi token hiện ra (chỉ hiện đúng 1 lần) và dán vào ô "Token" bên dưới.
  8. Điền tiếp Chủ sở hữu/tổ chức, Tên repository, Nhánh (thường là main) và Đường dẫn file (ví dụ data/kpi-nguyen-van-duc.json).
  9. Bấm "Kiểm tra kết nối" để xác nhận token hoạt động, rồi "Lưu lên GitHub" để lưu, hoặc "Tải từ GitHub" để lấy lại dữ liệu đã lưu trước đó (sẽ ghi đè dữ liệu hiện tại trong app).
Lưu ý bảo mật: không chia sẻ token này cho người khác, không dán token trên máy tính công cộng/dùng chung, và nên đặt ngày hết hạn ngắn cho token khi tạo.
